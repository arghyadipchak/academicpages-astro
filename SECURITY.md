## Reporting a Vulnerability

If you discover a potential security vulnerability in Academic Pages Astro, please report it responsibly:

1. **Private Disclosure**: Please do **not** open a public issue; use [GitHub Private Vulnerability Reporting](https://github.com/arghyadipchak/academicpages-astro/security/advisories/new) if available, or contact the maintainers directly
2. **Details**: Include a detailed description of the vulnerability, steps to reproduce, and any suggested remediations
3. **Response Timeline**: You will receive an acknowledgment within 48 hours and updates regarding the fix and disclosure schedule
